TransliteratorKeyboard

Write Tulu in any script.

Type Tulu in English letters or Kannada and see it in Tulu Lipi as you type. This only changes the script. It doesn't translate the meaning: neer stays neer, just written differently.

Your device doesn't have a Tulu Lipi font yet, so Tulu Lipi output will show as boxes. Copy-paste still works: the text is correct Unicode and will display on any device that has the font.

What to type

Capitals matter: A is a long ā, T D N L are the "tongue-curled" sounds. Casual ee and oo also work for long ī and ū.
