✍️ Tulu Lipi · Tigalari script

Read & write Tulu Lipi

Tulu's own script, letter by letter. Each one sits next to its Kannada twin, so if you can read Kannada you're already halfway there. Learn the letters, build syllables, trace them by hand, then test yourself.

🔤
Your device doesn't have a Tulu Lipi font yet. Tulu-Tigalari only joined Unicode in 2024 (version 16.0), so most phones and computers don't ship a font for it, and Tulu letters show up as empty boxes. Install any Tulu-Tigalari font and reload. You can still learn the Kannada pairs and sounds in the meantime. Site owners: put a font file at fonts/TuluTigalari.woff2 and every visitor gets it automatically.

Vowels · ಸ್ವರಗಳು

Tigalari is the older sister of the Malayalam script and was used along the coast for Tulu and Sanskrit palm-leaf manuscripts. It has no separate short e and o: one letter covers both lengths. Read the history of the script →

Build syllables

Just like Kannada, a consonant carries an "a" sound until a vowel sign changes it. Pick a consonant and watch it change.

How the vowel signs look and join depends on your font. Some fonts draw a few combinations differently from old manuscripts.
